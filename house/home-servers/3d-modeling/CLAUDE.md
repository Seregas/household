## 📍 ДЕ МИ ЗАРАЗ (стан на 2026-06-26)

Робимо **3U інтегрований корпус плати NAS** для 10″ Lab-RAX раку.
Зараз доробляємо **ДНО (board-tray)** — органічна розріджена Voronoi-павутина.

**Актуальний baseline дна: `board3u_voronoi_v6.stl`** — генерується скриптом
`build_board_tray_v6.py` (у цьому каталозі). Одне тіло, watertight, vol ≈ 157 500.

Що вже у v6:
- розріджена **Voronoi-павутина** 2 мм (24 комірки), доходить до обода всіх сторін;
- **глибина наростена назад** (обід Y77→Y92) — під увесь модуль RAM A відкрита павутина (вентиляція);
- **соти всередині 4 комірок пеедесталів** (органічна межа = край комірки) для жорсткості посадкових місць;
- **обід** 2.5 мм, задні кути заокруглені R10;
- **округлий валик** уздовж внутрішнього краю обода (продовження бортика з рейок);
- **пеедестали**: циліндр r7.5 (Z0-2) → конус r7.5→r5 (Z2-5.5) → циліндр r5 (Z5.5-7.5, площадка), ⌀4 наскрізь.

## 🛠️ ТУЛЧЕЙН (на компʼютері Клода / sandbox)
- Python: **trimesh + manifold3d** (`engine='manifold'`), **shapely** (`voronoi_diagram`, `unary_union`, `buffer`), **scipy** (`Voronoi`, Lloyd), numpy, matplotlib.
- `pip install --break-system-packages trimesh manifold3d shapely scipy rtree numpy`
- Процес: boolean на watertight-мешах → STL у `/mnt/user-data/outputs/` → рендер PNG → **present_files** (перевідправити, якщо «не бачу картинки»).
- Базу копіювати на компʼютер Клода через **copy_file_user_to_claude** (MINI_ITX_GPU_FAN.stl → поряд зі скриптом як `board3u_base.stl`).
- ⚠️ STL/PNG бінарні — у проєктну теку Маку пишемо лише ТЕКСТ (скрипти, доки). Готові STL користувач завантажує з чату.

## ⚙️ КЛЮЧОВІ УРОКИ ТУЛЧЕЙНУ
- **matplotlib PolyCollection** заливає всі трикутники → круті стінки виглядають «віялами». Ненадійно для оцінки суцільності. Справжні тести: `m.contains`, `m.ray.intersects_location`. Для чесного рендеру дна знизу: фільтр `nrm[:,2]<-0.85 & cen[:,2]<0.6`.
- **`extrude_polygon` на складній павутині буває НЕ watertight.** Фікс: після екструду `merge_vertices()` → `update_faces(nondegenerate_faces())` → `fill_holes()` → `fix_normals()` (див. `extrude2d` у скрипті).
- **Заливку/соти робити як БУФЕРОВАНІ ЛІНІЇ** (стінки кілець), а НЕ «суцільне мінус отвори» — останнє дає невалідні полігони, коли отвір торкається нерівної межі комірки (→ не-watertight).
- **Після фінального union** прибрати вироджені фрагменти на кутах: лишити найбільше тіло (`max(split, key=volume)`), потім `nondegenerate_faces`. Перевіряти `is_watertight` і `len(split)==1`.
- Тримати все, що під платою, **нижче Z2.5** (низ модулів памʼяті).

## 📜 ІСТОРІЯ ЕВОЛЮЦІЇ ДНА
- Стільникове / spider / **isogrid** — відкинуто (ізогрід з великими трикутниками теж не зайшов візуально).
- Обрано **Voronoi** (органіка). Ітерації v1→v6:
  - **v3** — павутина доходить до обода (через `voronoi_diagram` з обрізкою по контуру).
  - **v4** — глибина наростена назад до Y92 (вентиляція під RAM A).
  - **v5** — заокруглені задні кути, обід 2.5, перші соти-патчі (відкинуто — трикутні фрагменти), профіль пеедестала циліндр-конус-циліндр.
  - **v6** — соти в САМИХ комірках Voronoi (органічна межа), валик обода, прибрано перемички-зв'язки пеедестал→павутина (їх замінили соти в комірці).

## ✅ ЗАЛИШИЛОСЬ ЗРОБИТИ
1. **Дрібні артефакти на пеедесталах** (відкладено — користувач помітив, гляну згодом).
2. **ФРОНТ (база, ще не чіпали):**
   - кнопка **рівно ⌀12** (у користувача лише 12-мм кнопки);
   - дві старі ⌀13 діри **зашити** стільниками фронтальної панелі;
   - рішення по двох вертикальних **прорізах** (лишати/прибрати);
   - **виріз зверху під планку HBA** LSI 9217-8i.
3. **Верхній 1U:** PSU Flex ENP-7660B + JetKVM. Вхід 220В збоку; KVM екран спереду / конектори ззаду; KVM у вільній половині 1U поряд з PSU.
4. **Інтеграція з дисковою кліткою 2U** (окремий STL, 1:1).
5. (можливо) перенести **рейкові вушка** на новий задній край Y92, якщо так монтуватиметься в рейку.

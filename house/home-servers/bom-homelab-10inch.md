## Контрольні перевірки перед оплатою

- [ ] Версія плати CWWK: саме **i5-12450H** (не U300e — у нього 14 ліній замість 28), кіт саме **4×U.2**

- [ ] Кабелі під HBA: **SFF-8087**→SATA forward (не 8643, не reverse)
- [ ] ECC-модулі в Memory QVL AM5D4ID; DAC для NAS — Intel-coded
- [ ] ENP-7660B: активний PFC 200–240В; має EPS 4+4

## Перший запуск NAS (пам'ятка)

1. БЖ з джампером → плата стартує сама (перевірити Restore AC Power Loss = Power On у BIOS).
2. HBA: переконатися, що BIOS бачить option ROM, диски видно в `lsblk`; `smartctl -a` по кожному.
3. badblocks/повний SMART-тест дисків до створення пулу; boot-дзеркало з 2× SATA SSD.
4. 82599: якщо DAC не підніметься — `options ixgbe allow_unsupported_sfp=1` (план Б, з Intel-coded не знадобиться).
5. Scrub-марафон тиждень під навантаженням до заливки реальних даних.

# PDU / POWER-ЮНІТ СТІЙКИ (проектування, червень 2026)

## Концепція
Окремий sled під Lab-RAX (плаский горизонтальний, ~1.5–2U) з трьома фізично розділеними зонами:
**220В силова / комутація (реле) / слабкострум+DC**. Силову частину 220В Сергій робить сам як електрик
(досвід панелі Боровиці), на готових/перевірених компонентах — не саморобні 220В-реле.

## Принцип розподілу (інженерна знахідка)
Критичний домен (DNS/мережа/HA/безпека) виявився переважно DC/PoE або з власним резервом,
а важкі робочі машини — AC. Три домени:
1. **AC керовані** (через реле з/без виміру): NAS, Proxmox + запас
2. **AC некомутовані** (завжди під напругою, окремі розетки без реле): Ajax NVR, Mac mini
3. **DC 48В шина** (від спільного блока): RB5009 + CRS305 + PoE-периферія

## Відкриті питання для механіки (коли почнемо креслити sled)
1. Кількість розеток C13 + розподіл керовані/некомутовані (керовані: NAS, Proxmox + запас; некомут.: NVR, Mac mini)
2. Орієнтація вводу 220В (назад/вбік), один ввід чи кілька
3. Глибина sled-а → визначає DC-блок (UHP vs LRS-150F) і чи влазить 199мм
4. Монтаж реле → визначає вибір Shelly(DIN) vs 8CH(стійки)

# КОРПУСИ 3D-ДРУК — ОСНОВА Lab-RAX (проектування)

## База
**Lab-RAX** від mklements (makerworld 1294480, bolted-версія 1464819 — без втулок, M6/#10-32 болти).
Готова модульна рама (рама+пости+панелі), 20.9k завантажень. Колекція аксесуарів:
makerworld collections 6647137 (depth-spacers, fan-mounts тощо).
Проектуємо НЕ корпуси з нуля, а **sled-вставки** під готовий стандарт Lab-RAX.

## Розміри 10" стійки (канонічні, EIA-310)
- Зовнішня ширина фронту: **254 мм** (10")
- **Корисна ширина між рейками: 222.25 мм** (8.75") — головне обмеження
- Рейки 15.875 мм (0.625"), 1U = 44.45 мм
- Принтер Bambu A1: поле 256мм → панель 254мм ВПРИТУЛ → друк по частинах

## Спільні принципи (фундамент обох корпусів)
1. Рама+знімні панелі (не моноблок); з'єднання M3 у heat-set втулки (розбірність)
2. Орієнтація друку: навантаження ВЗДОВЖ шарів; вуха під рейки — площиною в стіл, 4-5 ліній стінок, 100% інфіл у зонах отворів
3. Матеріал: **PETG** база; **ASA** біля гарячого (VRM/HBA/БЖ); PLA — НІ (попливе)
4. **Повітря — наскрізний принцип:** холодне спереду → крізь гарячі точки → витяжка ззаду; спрямований тунель, не "вентилятор у стінку"
   - NAS: продув КРІЗЬ кейдж дисків + вздовж радіатора HBA
   - Proxmox: продув вздовж VRM/NIC (саме перегрів VRM убив Топтон!)
5. Вентилятори: Arctic P8(80мм)/P12(120мм) PWM (4-pin)

# РОЗШИРЕННЯ СТОРЕДЖУ / PCIe НА PROXMOX (на майбутнє, за потреби)

## Карта ліній AM5D4ID2 (ВИПРАВЛЕНО 23.06.2026 — попередня версія була з чужої плати)
⚠ Стара карта була взята з block diagram **-2L+/BCM** — це ІНША модель (1× M.2 Gen4 + OCuLink + Broadcom 10G).
Чиста **AM5D4ID2** натомість: **2× M.2 Gen5 x4**, 2× i210 1GbE, **БЕЗ OCuLink** (підтверджено фізично + spec asrockrack.com).
Розподіл ліній CPU (Granite Ridge, 28 ліній; точна PCIE-нумерація з block diagram саме цієї версії ще не звірена,
ширини слотів — зі специфікації):
- **x16 слот** PCIEx16 SLOT1 (Gen5 x16), біфурцирується
- **M.2_1** (Gen5 x4) — нативний
- **M.2_2** (Gen5 x4) — нативний (друга M.2 замість OCuLink, що на -2L+/BCM забирав ці лінії)
- BMC/IPMI (x1)
- 2× бортова мережа i210 (1GbE)

Біфуркація слота підтверджена в BIOS: **PCIE7 Link Width: x16 / x8x8 / x8x4x4 / x4x4x8 / x4x4x4x4**.
CX4121C електрично потребує лише **x4** (2×10G лізе в x4 Gen4 з запасом), хоч механічно це x8-карта.

## Поточна схема (без рига, $0 додатково) — ОНОВЛЕНО 23.06.2026
CX4121C у слот напряму (x16) + M.2_1 (система, 990 Pro 1TB) + M.2_2 (VM/процесинг, 2TB).
= 10G + **2 нативних NVMe**, БЕЗ OCuLink-перехідника ($20 і точку відмови прибрано — на платі дві справжні M.2).
Конфіг дисків: один на систему, один на VM+інше; **БЕЗ дзеркала** (PBS-бекапи на NAS покривають).
Дзеркало boot — ПІД ПИТАННЯМ: 1TB тісно під систему+VM разом, тож спершу визначаємось з обсягом дисків,
потім рішення mirror vs split. Третій NVMe нативно вже нема куди — лише через слот (риг) або U.2-адаптер у слот.

## РИГ-РОЗГАЛУЖУВАЧ — два варіанти на майбутнє (ADT-Link F3312A серія)
Гібрид "слот + рознесення кабелями": материнська плата в слот x16, винесені фізичні PCIe-слоти на FFC-кабелях
(turn 90°, Gen4, екранований, UL). У кожен винесений слот — БУДЬ-ЯКА карта (мережа/диск-адаптер/HBA/GPU).
Сторінка: https://www.adt.link/product/F3312A.html | Магазин: https://www.adt.link/product/F3312A-Shop.html

| Артикул | Поділ | Слоти | Ціна (25/50см) | Кому |
|---|---|---|---|---|
| **F3312A-844S** | **x8x4x4** | x8 + x4 + x4 (3 слоти) | $240 / $250 | якщо в планах карта, що хоче саме x8 (25/40G NIC, HBA, GPU) |
| **F3312A-Q4S** | **x4x4x4x4** | 4× x4 (4 слоти) | $290 / $300 | КРАЩЕ за профілем: мережа x4 + **3 вільні x4**; плата підтримує x4x4x4x4 |

**Висновок по вибору:** Q4S логічніший — CX4121C потрібен лише x4, тож x8-канал 844S марнується наполовину;
Q4S дає мережу + 3 вільні канали (рівно початковий запит "3 вільні"). 844S брати ТІЛЬКИ якщо буде карта під фізичний x8.

   кабелі дають свободу, але об'єм під карти лишається проблемою компактного rack.

**Дешева альтернатива для "мережа + диски" (НЕ універсальні карти):**
слот → CX4121C + M.2_1 + OCuLink→M.2/U.2 адаптер ($20) = 10G + 3 диски за $20 замість $300-рига.
Риг виправданий ЛИШЕ якщо мета — різнотипні карти в кількох слотах (не самі диски).

- CRS305: тонкий/вузький, метал перфорований з усіх боків, без вентилятора (можна поряд із чимось)
- Mac mini M4: трохи >1U → 2U-полиця
- Ajax NVR: 1U повністю
- Ajax Hub: **виносимо на бічну стінку стійки** (радіо 868 + тепло)
- JetKVM: з NAS, якщо влізе

## Proxmox — напрям кулера NH-D12L (рішення)
- Башти асиметричні (одна ширша). Різниця «вузька-vs-широка першою» — **знехтувано** (~1°C). Напрям НЕ обирати за шириною башт.
- Напрям вільно реверсується: перевісити/перевернути вентилятор між баштами.
- **Критерій: VRM на боці ІНТЕЙКУ (свіже повітря), НЕ під вихлопом кулера** (перегрів VRM убив стару плату TOPC). Тобто видув кулера — у бік RAM.
- I/O фіксовано спереду → вісь кулера ліво-право фіксована; вільний лише напрям. Сторону видуву диктує фізичне розташування VRM: став вентилятор так, щоб VRM був на вході. Той борт стійки, куди йде видув, — вентилювати.

## ОНОВЛЕННЯ АРХІТЕКТУРИ (сесія 25.06.2026, ч.2)
- **NAS зафіксовано = 4U** (поки що). Наслідок: електронна дека = 2U → вертикальний HBA влазить (~69 < 89 мм), **рейзер більше не обов'язковий**, HBA-габарити НЕ гейтять висоту.
- **Кожен пристрій — ОКРЕМА одиниця, без групування в спільний корпус.** NAS (4U), PDU (2U), Proxmox (4U) — окремі блоки. RB5009, CRS305, Mac mini, Ajax NVR — кожен своя окрема одиниця. Комбо Mac+RB / NVR+CRS — СКАСОВАНО.
- JetKVM — усередині NAS. Ajax Hub — на стіні (поза стійкою).
- **Кейдж = ПОКУПНИЙ металевий 6-bay 2U** (250 мм з кабелями, у наявності). Отже 5 кг тримає метал + сталеві напрямні; друкована частина = лише каркас-носій + полиця електроніки + кріплення фанвола → навантаження на пластик мінімальне. Більшість друкованих деталей <256 мм друкуються суцільно; довгі лише бічні рейки.


## PROXMOX-БЛОК — лейаут AM5D4ID2 (з мануалу + фото, 25.06.2026)
- Орієнтація: I/O-грань (2×i210 LAN, HDMI, VGA, USB, IPMI) = ПЕРЕД. 170 мм — по ширині стійки, 208 мм — глибина.
- Плата стає МІЖ направляючими (не врівень із краєм) → ефективна ширина <222 (стінки sled). «БЖ у щілину збоку» — відкинуто.
- Один борт = DIMM ×4 + ATX12V1/V2 + VRM; інший борт = PCIE7 (тут стоїть CX4121C, SFP28 спереду). Сокет — центр. M2_1 (2280) спереду-ліво від сокета, M2_2 (2280) ззаду-право біля DIMM — обидва низькі, потоку не заважають.
- **Кулер NH-D12L: поперечний обдув між DIMM/VRM-бортом і NIC-бортом.** РІШЕННЯ: інтейк з боку VRM/DIMM (свіже на VRM), видув у бік NIC. Вентилювати борт із боку NIC. Реверс (вихлоп на VRM) — ЗАБОРОНЕНО (VRM убив стару плату).
- **Flex-БЖ ENP-7140B1: на ребро (40.5 завглиб) ПОПЕРЕК, ЗЗАДУ за платою** (208 плата + ~40.5 БЖ < 280 глибини). Кросс-флоу-борти лишаються чисті. AC-ввід ззаду (це не «порт», конвенцію не порушує).
- NIC стоїть «стіною» на боці видуву → для 65W некритично, борт вентильований, радіатор NIC обдувається по дорозі. За потреби — NIC плиском на рейзері.
- Висоти: NH-D12L 145 < 4U(178) ✓; NIC full-height ~111 < 178 ✓.
